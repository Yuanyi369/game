# 影石 Insta360 Ace Pro 2 · 3D 结构拆解实验室

一个纯代码构建的 **Insta360 Ace Pro 2** 交互式 3D 拆解可视化页面。深色实验室视觉、点击部件独立拆解、自发光轮廓、参数标注、部件清单与操作引导都集成在同一页面中。

> 本页为非官方概念设计。外观参考公开产品资料，内部结构布局为艺术化演绎，不代表真实拆机结构。

## 直接打开

**双击 `index.html` 即可。** 页面使用本地打包的 Three.js 与程序化纹理，不需要服务器、网络或任何外部 3D 模型文件。

如果浏览器限制本地文件访问，也可以在当前目录启动一个静态服务器：

```bash
python -m http.server 8765
# 然后访问 http://127.0.0.1:8765
```

## 交互方式

| 操作 | 功能 |
| --- | --- |
| 鼠标拖拽 / 单指拖动 | 旋转观察视角 |
| 滚轮 / 双指捏合 | 缩放视距 |
| 点击部件或部件标注 | 选中并拆解该部件，查看详情 |
| 再次点击「归位该部件」 | 收起当前部件 |
| 拆解整机 | 9 个部件依次沿各自轴向分离 |
| X-RAY | 机身壳体透明化，观察传感器、主板、散热等内部结构 |
| 自动旋转 | 开启 / 关闭缓慢自转展示 |
| 正视 / 侧视 / 俯视 / 复位 | 快速切换相机视角 |
| `E` / `X` / `A` / `R` | 拆解整机 / 透视 / 自动旋转 / 复位视角 |
| `Esc` | 关闭帮助或取消选择 |

手机端：轻点部件会选中并拆解；滑动是旋转，不会误触。点选后底部「核心部件 / 参数」抽屉可展开完整清单与详情。

## 功能与视觉

- **纯程序化 3D**：机身、徕卡镜头、影像传感器、双芯主板、翻转屏、电池、麦克风防风罩、I/O 模块、磁吸底座、铜质散热鳍片均由 Three.js 几何体拼装。
- **程序化纹理**：镜头刻字、相机屏幕 UI、PCB 电路、电池标签、穿孔扬声器网格、品牌标识全部通过 Canvas 2D 实时绘制。
- **拆解动画**：每个部件独立管理拆解进度，带延迟、缓动、轴向引导虚线与发光轮廓。
- **标注系统**：3D 锚点实时投影到屏幕，粒子引出线在画布上绘制；标注会避让、收束在安全区域内，并针对移动端缩放偏移。
- **材质与光效**：物理材质、环境反射、菲涅耳玻璃、ACES 色调映射、UnrealBloom、OutlinePass 自发光边缘。
- **界面**：部件清单、选中详情、技术参数、装配进度、视图预设、帮助弹窗。
- **响应式**：桌面分栏、短屏紧凑模式、平板/手机抽屉式部件面板。
- **可访问性**：语义按钮、键盘操作、`aria-live` 状态、`prefers-reduced-motion` 支持。

## 开发与构建

源代码使用 ES Modules 组织，并通过 esbuild 打包成可直接双击运行的单文件 `bundle.js`。

```bash
npm install
npm run build       # 生产构建（压缩）
npm run build:dev   # 未压缩构建，便于调试
npm run preview     # 可选：使用 python 启动 8765 端口静态服务
```

Three.js 版本：`0.170.0`。
